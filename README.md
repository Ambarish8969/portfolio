# Ambarish Bhagawati — Portfolio

This is a simple static portfolio site you can host on GitHub Pages.

Files:

- `index.html` — site markup
- `styles.css` — site styles
- `assets/resume.pdf` — placeholder resume (replace with your PDF)

Quick start:

```bash
git init
git add .
git commit -m "Initial portfolio"
# create repo on GitHub and push, then enable Pages from `main` branch (root)
git branch -M main
git remote add origin <your-git-remote>
git push -u origin main
```

GitHub Pages:

1. Push to GitHub.
2. Go to your repo Settings → Pages and select `main` branch, root folder.
3. Save and wait; your site will be published at `https://<username>.github.io/<repo>`.

Customization:

- Replace `assets/resume.pdf` with your real resume.
- Edit content in `index.html` (name, links, project details).
- Update colors or fonts in `styles.css`.
